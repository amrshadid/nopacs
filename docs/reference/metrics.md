# Metrics

What `GET /metrics` returns, in the Prometheus text format (version 0.0.4). The server answers it on its local
socket with no key; on the network it needs a key that holds a grant on the installation. A scrape writes no audit
entry. Every name begins `nopacs_`; a label's values come from fixed sets of the server, never from a request, so the
number of series stays bounded whatever callers send.

| Metric | Type | Labels | What it counts or measures |
|---|---|---|---|
| `nopacs_requests_total` | counter | `code`, `method` | Requests answered, by method and API code. |
| `nopacs_request_duration_seconds` | histogram | `method` | Time from a request's arrival to its answer, by method. |
| `nopacs_requests_in_flight` | gauge | - | Requests being served now. |
| `nopacs_tenants` | gauge | `state` | Tenants by state. |
| `nopacs_audit_entries_written_total` | counter | - | Audit entries of refusals and reads that a log took. |
| `nopacs_audit_entries_failed_total` | counter | - | Audit entries a log refused one by one, or that were not valid. |
| `nopacs_audit_entries_dropped_refusals_total` | counter | - | Audit entries of refusals dropped because their queue was full or the server was closing. |
| `nopacs_audit_entries_dropped_records_total` | counter | - | Audit entries of allowed requests dropped because their queue was full or the server was closing. |
| `nopacs_audit_entries_dropped_writes_total` | counter | - | Audit entries the writer gave up on: the database did not answer after the retries, or the close deadline passed. |
| `nopacs_audit_entries_rerouted_total` | counter | - | Audit entries for a tenant's log written to the master's because the tenant's did not answer. |
| `nopacs_audit_entries_notices_total` | counter | - | Audit entries the writer wrote to say entries were dropped. |
| `nopacs_key_last_use_marks_written_total` | counter | - | Last-use marks of keys the database took. |
| `nopacs_key_last_use_marks_dropped_total` | counter | - | Last-use marks of keys dropped because their queue was full or the server was closing. |
| `nopacs_key_last_use_marks_failed_total` | counter | - | Last-use marks of keys the database refused or failed. |
| `nopacs_audit_seal_failures_rolled_back_total` | counter | - | Anchors a sealing pass kept because the log they name no longer descends from them. |
| `nopacs_audit_seal_failures_unencodable_total` | counter | - | Sealing passes held back by an unsealed audit entry that cannot be encoded. |
| `nopacs_audit_seal_failures_other_total` | counter | - | Audit logs a sealing pass could not seal, anchor or check for another reason, mostly a database that did not answer. |
| `nopacs_audit_unsealed_oldest_age_seconds` | gauge | - | Age of the oldest audit entry the last sealing pass left unsealed, 0 for none. |
| `nopacs_replica_lag_seconds` | gauge | `replica`, `tenant` | How long the oldest scan not in step on a replica has waited, by tenant and replica, 0 when every scan is in step. |
| `nopacs_replica_scans_behind` | gauge | `replica`, `tenant` | Scans not in step on a replica (pending, copying or damaged), by tenant and replica. |
| `nopacs_scrub_verified_share` | gauge | `storage`, `tenant` | Share of a storage's objects a scrub read whole within scrub.interval, by tenant and storage, as its last scrub left it. |
| `nopacs_scrub_oldest_unverified_seconds` | gauge | `storage`, `tenant` | How long a storage's object waiting longest has gone unread by a scrub, by tenant and storage, 0 when every one is within scrub.interval. |
| `nopacs_scrub_overdue_objects` | gauge | `storage`, `tenant` | Objects of a storage not read whole by a scrub within scrub.interval of their last read, by tenant and storage. |

The buckets of `nopacs_request_duration_seconds`, in seconds, are fixed so a dashboard built on them keeps
working: 0.001, 0.0025, 0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10, 30.
