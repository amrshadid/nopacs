# Settings reference

Every setting the server knows, with its default, where it may hold a value, who may set it and
whether a change needs a restart. A setting is read with `nopacs setting get` or `list` and changed
with `nopacs setting set` and `unset` (`--tenant NAME` for a tenant's value). A period is a whole number
followed by `s`, `m`, `h` or `d`; a size is a whole number of bytes, or a number followed by `KiB`, `MiB`,
`GiB`, `TiB` or `PiB`.

None of these needs a restart: each is read from the database when it is used, or kept for a few seconds.
When a change is seen, setting by setting, is on [the settings page](../operate/settings.md#which-changes-take-effect-without-a-restart).
The server's own flags and files (`--listen`, the key file, the data directory) are read once, at start.
