# Event types

A tenant's events are its live feed: `nopacs watch <tenant>` and `MonitorService.Watch` follow them, and
`--type` (`types` in the call) keeps only the types named. An event is written in the same transaction as the
change it reports, and is kept for the tenant's `events.retention`. A client skips an event of a type it does
not know and takes its cursor, so a type added in a later version breaks no client.

| Event type | Number | What it reports |
|---|---|---|
| `ASSOCIATION_FAILED` | 1 | A receiver turned callers away. |
| `RECEPTION_STEP` | 2 | A reception reached a step. |
| `FILE_QUARANTINED` | 3 | A file was quarantined. |
| `QUARANTINE_DECIDED` | 4 | A quarantined file was released or rejected. |
| `RECEIVER_HEALTH` | 5 | A receiver went up or down, or down for another reason. |
| `STORAGE_SPACE` | 6 | A storage became nearly full, or recovered. |
| `FRAMES_ADDED` | 7 | The pass that gives frame tables to the metadata of scans archived before them rewrote a scan's metadata, or ended. |
| `JOB_STEP` | 8 | A job was made or reached a state. |
| `JOB_PROGRESS` | 9 | A running job's counts, at most once every 10 seconds per job. |
| `SENDER_HEALTH` | 10 | A sender went up or down, or down for another reason. |
| `SCRUB_FINDING` | 11 | A scrub recorded a finding, or cleared one. |
| `CATALOG_CHANGED` | 12 | A correction changed what the catalog shows: a delete committed, undone or purged; a relabel or a replace published. |
| `CATALOG_REBUILT` | 13 | A rebuild made a new catalog the one in use, or a restore or an import rebuilt it; the first event of a new history. |
| `REPLICA_BEHIND` | 14 | A replica's lag passed the tenant's replica.lag-alert, or fell back under it. |
| `STORAGE_SWITCHED` | 15 | A switch made a replica the primary (ReplicaService.SwitchStorage), or was refused and every write resumed on the old place. |
| `HOLD_CHANGED` | 16 | A hold was placed or released, or found on a storage and made active. |
| `RETENTION_CLOCK` | 17 | The tenant's retention was paused for a clock jump, or resumed when an admin confirmed the time. |
